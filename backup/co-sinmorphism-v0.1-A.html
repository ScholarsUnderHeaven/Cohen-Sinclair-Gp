Co-Sinmorphism UI Kit v1

Frosted-glass website kit — hero, pricing, shop, blog, dashboards and 100+ components in one file. Porcelain light and graphite dark via the sun/moon pill (top right, light by default). Text contrast meets WCAG AA in both themes. All JavaScript is class-based, so duplicated blocks keep working in Webstudio.

Using this kit in Webstudio (drag & drop)

This is one self-contained file: the <style> lives in the head, the markup in the body, the <script> at the end. No build step, no dependencies (the Poppins font link is optional).

  1. Import once: in Webstudio add a Custom Code / HTML Embed block and paste the whole file — or paste the <style> contents into one global embed and copy components as needed.
  2. Copy components: every section is wrapped in <!-- WS:BEGIN … --> / <!-- WS:END … --> comments. Copy anything between a pair — a whole section, or a single card like data-ws="finance" — into a new embed.
  3. Duplicate freely: dropdowns, sliders, switches, steppers, star ratings, segmented controls, paginations and accordions are all class-based with event delegation — copies keep working with zero code changes.

Note: the Geography map is a live Google Maps embed — it needs an internet connection and renders in a real browser (it stays blank in offline previews). If Google is blocked by your network or ad-blocker, the card automatically falls back to OpenStreetMap. Everything else in the kit works fully offline.

FAQ

How do I copy a section into Webstudio?

Every section sits between WS:BEGIN and WS:END comments. Copy the whole block, paste it into an embed, and the styles come along — tokens, frost and all.

Does dark mode really keep contrast?

Yes. Every text token was solver-checked against its surface to WCAG AA (4.5:1), and the proof table ships with the kit.

Can I use the shop without a backend?

The cart, drawer and checkout flow are fully interactive demos. Point the checkout handler at your payment provider when you go live.

Is the chat bot real?

It is a friendly canned-reply demo. Swap one function for your support API and it becomes the real thing.

What license covers the kit?

Use it in personal and commercial projects freely. The only thing you cannot do is resell the kit itself as a kit.

What is neumorphism?

A soft UI style where elements appear extruded from or pressed into the background using dual light/dark shadows.

Does it work on dark mode?

Yes, but the shadow colors need to be re-tuned to the dark background to keep the effect readable.
